# Wiki location

The wiki content is in `articles/<wiki-name>/`. Each `.md` file is a wiki page; images are in `articles/<wiki-name>/.attachments/`.

Read from `articles/` to answer questions about the wiki.

# Citing wiki pages

Every synced `.md` file ends with a footer like:

```
---
**Source:** [<page title>](https://dev.azure.com/<org>/<project>/_wiki/wikis/<wiki>/<id>)
```

When you reference, quote, or summarize a wiki page in your reply, append a `Source:` line right after the relevant paragraph or claim. Include both the page title and the URL, taken verbatim from the footer:

    Source: <Page Title> — https://dev.azure.com/<org>/<project>/_wiki/wikis/<wiki>/<id>

If a single answer pulls from multiple pages, repeat the `Source:` line after each block of content drawn from a different page.
